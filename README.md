### 4. Prerequisites & Local Development

#### Prerequisites
- JDK 21 (Eclipse Temurin / OpenJDK)

#### Installation
```bash
git clone https://github.com/reginaldalfret/portfolio-springboot.git
cd Portfolio-SpringBoot
./mvnw clean compile
```

#### Running Development Server
```bash
./mvnw spring-boot:run
```

#### Production Build
```bash
./mvnw clean package -DskipTests
```

#### Running Test Suite
```bash
./mvnw test
```
